# Shift Schedule Calendar

一个纯浏览器使用的排班 ICS 生成页面。打开 `index.html`，选择排班 Excel，页面会在本地解析表格并下载 `.ics` 文件；真实班表不会上传到仓库。

## 使用方法

1. 双击打开 `index.html`，或把它部署到 GitHub Pages。
2. 选择排班 Excel。
3. 人员默认会选择“张艳菊”；如果表格里没有这个姓名，再手动选择。
4. 点击“生成并下载 ICS”。
5. 把下载得到的 `.ics` 文件上传到你自己的存储位置，再把上传后的 ICS 地址添加到日历订阅。

## 公开仓库注意事项

- 不要提交真实排班 Excel。
- 不要提交生成后的 `.ics`，除非你确认日历内容可以公开。
- `input/`、`dist/` 和 `*.ics` 已经被 `.gitignore` 忽略。

## 表格要求

- 默认读取第一个工作表。
- 前 8 行内需要有一行日期表头，至少包含 7 个日期列。
- 表头上方或表头行里最好有“姓名”或“名字”列；如果没有，页面默认第 4 列为姓名列。
- 页面会导出目标姓名所在行的班次代码，并尝试从下一行读取工时。
